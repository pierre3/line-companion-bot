# チュートリアル: バーチャル相棒育成Bot × MINI Appショップを作る

これは `LineCompanionBot` を空のディレクトリから動くアプリまで組み立てていく過程を、いっしょに
追体験していくハンズオンです。主役は**`Line.OpenApi.*` パッケージ群がどう配線し合って**1つの
現実的なシステムになっていくか——ユーザーがチャットでバーチャルペットを育てるLINE Botと、
アプリ内課金（IAP）でアイテムを買えるMINI Appショップを組み合わせ、購入完了がチャットに通知される、
そんなアプリを組み上げていきます。

各パッケージのAPIが何をするかを一から説き直すのが狙いではありません——それは
[`line-dotnet` マニュアル](https://github.com/pierre3/line-openapi-dotnet)の概念記事にゆずります。
ここで見ていきたいのはあくまで*統合*のほうです: Messaging・Webhook・MINI Appの継ぎ目と、それらを
噛み合わせるための設計判断です。

## このチュートリアルの構成

出発点は何もない状態です。そこから——`dotnet new` でソリューションを雛形生成し——1章につき1つの
実装ステップを、順に積み上げていきます。各章の終わりには必ず、**Visual Studio Code**で実行・観察
できるもの（F5で起動・デバッグ）が用意してあり、書いたばかりのピースが実際に動くのを数分と待たずに
確かめられます。第1〜8章はLINEアカウントが一切無くても自分のマシンだけで完全に検証でき、実チャネルが
要るのは第9章になってからです。

各章に示すコードは、リポジトリの最終状態と1:1で一致します。というのも、後の設計パスで何かが変わった
場合（設定バインディング、永続化の抽象化、レビューゲートでの修正）は、その最終形のほうを章が提示する
ようにしているからです。あとで学び直す羽目になる、古い版ではありません。

## 2つの成果物

このチュートリアルとアプリは、同時に完成させることを狙ったものです: アプリが*何を*にあたり、この
マニュアルが*どうやって*にあたる、という関係ですね。アプリが完成とみなされる前には3役レビューゲート
（コード/セキュリティ/テスト・アーキ）を通しており、そこから出た指摘は最後にまとめて付け足すのでは
なく、関係する各章にそのつど織り込んであります。ですから、いま読んでいる内容はそのまま、レビュー
済みの各ピースの最終形なのです。
