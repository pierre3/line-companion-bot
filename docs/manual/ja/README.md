# チュートリアル: バーチャル相棒育成Bot × MINI Appショップを作る

`LineCompanionBot` を、空のディレクトリから動くアプリまで一緒に組み立てるハンズオンです。テーマは、
**`Line.OpenApi.*` パッケージ群を組み合わせて**1つの実用的なシステムに仕上げること。作るのは、チャットで
バーチャルペットを育てるLINE Botと、アプリ内課金（IAP）でアイテムを買えるMINI Appショップを
組み合わせ、購入するとチャットに完了通知が届くアプリです。

各パッケージのAPIを一から解説するのが狙いではありません。それは
[`line-dotnet` マニュアル](https://github.com/pierre3/line-openapi-dotnet)の概念記事に譲ります。
ここで扱うのは*統合*の部分、つまりMessaging・Webhook・MINI Appのつなぎ目と、それらを噛み合わせる
ための設計判断です。

## このチュートリアルの構成

出発点は何もない状態です。`dotnet new` でソリューションを雛形生成し、1章につき1つの実装ステップを
順に積み上げていきます。各章の終わりには必ず、**Visual Studio Code**で実行・観察できるもの（F5で
起動・デバッグ）が用意してあり、書いたばかりのコードが動くことをその場で確かめられます。第1〜8章は
LINEアカウント無しで自分のマシンだけで検証でき、実チャネルが必要になるのは第9章からです。

各章のコードは、リポジトリの最終状態と1:1で一致します（コード内のコメントだけは、読みやすさのために
日本語へ訳しています）。設定バインディングや永続化の抽象化、レビューでの修正など、後の工程で変わった
箇所は、章のほうも最終形に合わせてあります。あとで古い版を学び直す必要はありません。

## 2つの成果物

このチュートリアルとアプリは、同時に完成させることを狙っています。アプリが*何を*、このマニュアルが
*どうやって*にあたります。アプリを完成とみなす前に3役のレビューゲート（コード/セキュリティ/
テスト・アーキ）を通しており、そこで出た指摘は最後にまとめて付け足すのではなく、関係する各章に
織り込んであります。いま読んでいる内容は、そのままレビュー済みの最終形です。
